# 🎮 Connect Four Game in Python

This is a simple two-player Connect Four game built using Python.

## 🚀 Features
- Two-player terminal game
- Win detection (horizontal, vertical, diagonal)
- Input validation
- Easy to run

## ▶️ How to Run

Install numpy:

pip install numpy

Run the game:

python connect_four.py
